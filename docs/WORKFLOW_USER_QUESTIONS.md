## 🎤 **INTERVIEW CONDUCTING TIPS**

"आज हम सिर्फ यह समझना चाहते हैं कि आप JamureChat को कैसे use करते हो। कोई right-wrong नहीं है।"

- User को बोलने दो बिना interrupt किए
